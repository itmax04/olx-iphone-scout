# OLX iPhone Scout

Приватное однопользовательское веб-приложение для мониторинга публичных страниц
OLX Украина. Приложение по сохраненным поисковым URL находит объявления iPhone,
убирает дубли, ведет историю цен, детерминированно считает ожидаемую прибыль
перепродажи (формула profit-v1, точная арифметика Decimal), опционально делает
AI-анализ текста объявления через OpenAI (строгая JSON-схема, жесткие лимиты
расходов) и шлет уведомления в Telegram. Учет сделок (покупка/продажа,
фактическая прибыль) ведется вручную владельцем.

Важно: приложение **никогда не пишет продавцам, ничего не покупает и не
продает само**. Оно только собирает публичную информацию и считает цифры.
Все решения принимает человек.

Стек: Python 3.13, Django 5.2, DRF, PostgreSQL 17, Playwright Chromium,
HTMX + Bootstrap (локальные ассеты), Docker Compose. Язык интерфейса — русский.

## Требования

- macOS (или Linux/Windows с Docker), 8 ГБ ОЗУ и ~10 ГБ свободного места.
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) — единственная
  программа, которую нужно установить. Python, PostgreSQL и браузер Playwright
  ставить на компьютер не нужно: все живет внутри Docker.

## Быстрый старт

Все команды выполняются в Терминале, в папке проекта.

1. Создайте файл настроек из шаблона:

```bash
cp .env.example .env
```

2. Сгенерируйте секретный ключ Django и вставьте его в `.env` в строку `DJANGO_SECRET_KEY=`:

```bash
openssl rand -hex 48
```

3. Сгенерируйте пароль администратора (минимум 12 символов) и вставьте его в `.env` в строку `ADMIN_PASSWORD=`:

```bash
openssl rand -hex 12
```

4. Впишите свой e-mail в `ADMIN_EMAIL=` в `.env` (логин по умолчанию — `owner`, переменная `ADMIN_USERNAME`).

5. Соберите и запустите все сервисы (первый раз занимает 5–15 минут):

```bash
docker compose up --build -d
```

6. Откройте http://localhost:8000 — войдите с логином `owner` и паролем из `.env`.

7. Сразу смените пароль на странице http://localhost:8000/accounts/password_change/ .

По умолчанию `MONITOR_ENABLED=false` и `AI_ENABLED=false` — **первый запуск не
обращается ни к OLX, ни к OpenAI**. Это сделано специально: сначала убедитесь,
что все работает на встроенных фикстурах (см. ниже), и только потом включайте
мониторинг.

Проверка без внешней сети (фикстурная приемка):

```bash
docker compose run --rm web python manage.py run_fixture_pipeline
```

Ожидаемый результат — строка `FIXTURE_PIPELINE=PASS` в конце вывода.
Повторный запуск не создает дублей.

Остановка (данные сохраняются):

```bash
docker compose down
```

**Никогда не выполняйте `docker compose down -v`** — флаг `-v` удаляет том с
базой данных, то есть все ваши объявления, историю цен и сделки.

## Тесты

Полный набор проверок (линтер, типы, тесты) запускается одной командой внутри
контейнера — так же, как в CI:

```bash
docker compose run --rm web ./scripts/ci.sh
```

Где выполнять: в папке проекта, при запущенном Docker Desktop.
Ожидаемый результат: все шаги завершаются без ошибок, код возврата 0.
При ошибке: прочитайте последний блок вывода — там указан упавший шаг
(линтер/типы/тесты) и конкретный файл.

Сценарий «цена снизилась» на фикстурах:

```bash
docker compose run --rm web python manage.py run_fixture_pipeline --price-drop
```

## Troubleshooting (кратко)

- **Порт 8000 занят** — закройте другое приложение на порту 8000 или поменяйте
  порт в `compose.yaml` (`"8001:8000"`).
- **`database system is starting up`** — база еще стартует; подождите 10–20
  секунд и повторите команду.
- **Не пускает логин / «слишком много попыток»** — защита от перебора
  блокирует на 15 минут после 5 неудачных попыток. Подождите и попробуйте снова.
- **Мониторинг сам встал на паузу** — OLX вернул CAPTCHA/403/429. Это штатная
  защита (safety-блок на 30 минут). Не пытайтесь обходить: подождите и
  возобновите с подтверждением риска на /settings/.
- Полная таблица ошибок: [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

## Примечание про legacy-папки

Папки `build/`, `qa/`, `outputs/`, `work/`, `deliverables/` — артефакты старой
задачи (черновики, отчеты, промежуточные материалы). Они **не входят в
приложение**, не используются кодом и могут быть удалены без последствий.
